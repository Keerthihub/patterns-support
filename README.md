# Patterns support

Help, bug reports and feature requests for **Patterns**, a generative grid plugin for Figma.

**[Open an issue](https://github.com/Keerthihub/patterns-support/issues/new)** (you'll need a free GitHub account), or [browse existing issues](https://github.com/Keerthihub/patterns-support/issues) first.

## Reporting a bug

Please include:

- What you did, what you expected and what happened instead
- The preset and seed you were using
- Whether you use Figma in the browser or the desktop app, and your operating system
- A screenshot, if it helps

## Before you post

Issues here are public. Don't share confidential designs. Recipes copied with **Copy JSON** can contain images, artwork and shape outlines sampled from your Figma file, so check them before pasting.
